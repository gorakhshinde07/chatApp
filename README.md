# chatApp
# Public Ollama Chat Application 💬

A lightweight, minimal AI chat interface built with **Python**, **Streamlit**, and the **Ollama Python API**. 

## Features
- **Streaming Responses:** Words appear in real-time as generated.
- **Dynamic Model Selection:** Automatically pulls a list of models active on your server.
- **Configurable Host:** Works locally or can be pointed to a remote public server URL.

## Local Quickstart

1. **Install Ollama**  
   Download and install Ollama from [ollama.com](https://ollama.com).

2. **Clone the Repository**
   ```bash
   git clone https://github.com
   cd YOUR_REPO_NAME
   ```

3. **Install Dependencies**
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the App**
   ```bash
   streamlit run chatApp.py
   ```
